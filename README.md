
# HỆ THỐNG QUẢN LÝ THIẾT BỊ PHÒNG HỌC

## 1. Giới thiệu
Xây dựng hệ thống quản lý thiết bị phòng học trên nền tảng điện toán đám mây.

Hệ thống hỗ trợ quản lý thông tin thiết bị, theo dõi tình trạng sử dụng và cập nhật thông tin thiết bị.

## 2. Công nghệ sử dụng
- Frontend: React
- Backend: Node.js, Express
- Database: MongoDB Atlas
- Quản lý mã nguồn: Git, GitHub
- Đóng gói ứng dụng: Docker
- Lưu trữ Image: Docker Hub
- Triển khai: Render

## 3. Cấu trúc dự án
- backend/: Chứa mã nguồn Backend API.
- frontend/: Chứa mã nguồn giao diện React.
- README.md: Tài liệu hướng dẫn dự án.
- .gitignore: Các tệp không đưa lên GitHub.

## 4. Chức năng chính
- Xem danh sách thiết bị.
- Xem chi tiết thiết bị.
- Thêm thiết bị mới.
- Cập nhật thông tin thiết bị.
- Xóa thiết bị.
- Tìm kiếm thiết bị.
- Theo dõi tình trạng thiết bị.

## 5. Hướng dẫn cài đặt
Sẽ cập nhật sau khi hoàn thành dự án.

## 6. Triển khai
- Frontend: Đang cập nhật.
- Backend API: Đang cập nhật.
- Database: MongoDB Atlas.
